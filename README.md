# CollabTrust

AI-powered influencer marketplace connecting emerging
creators with brands.

## Vision

Make influencer collaborations more accessible,
transparent, and efficient.

## Core Features

- Brand and creator marketplace
- AI-powered creator matching
- AI-assisted trust analysis
- AI campaign brief generation
- Automated collaboration workflows

## Technology Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma

## Project Structure

- `apps/web` - Frontend application
- `apps/api` - Backend API
- `apps/worker` - Background jobs and workflows
- `packages` - Shared code and AI components
- `docs` - Product and technical documentation
- `knowledge-base` - Central project knowledge
