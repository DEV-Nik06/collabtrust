# CollabTrust

AI-powered influencer marketplace connecting emerging
creators with brands.

## Vision

Make influencer collaborations more accessible,
transparent, and efficient.

## Core Features

- Brand and creator marketplace
- AI-powered creator matching
- AI-assisted trust analysis
- AI campaign brief generation
- Human-controlled collaboration workflows

## Technology Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma
